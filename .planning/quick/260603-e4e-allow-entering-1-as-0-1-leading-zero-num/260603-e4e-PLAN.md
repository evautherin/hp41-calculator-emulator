<objective>
Allow entering `.1` as `0.1` (leading-zero number entry), matching real HP-41CV
hardware: pressing the decimal-point key when no digits have been entered shows a
leading `0.`, and following digits build the fractional part.

Purpose: Hardware-faithful number entry. On a real HP-41CV, `.` `1` displays `0.1`,
not `.1`. The emulator currently pushes a bare `.` onto `entry_buf`, displaying `.1`.

Output: When `.` is pressed on an empty `entry_buf`, seed it with `"0."` instead of
`"."` in BOTH the CLI and GUI entry handlers. The display path renders `entry_buf`
verbatim, so seeding `"0."` makes the leading zero appear with no display-formatting
change; `flush_entry_buf` already parses `"0.1"` correctly via `Decimal::from_str`.
</objective>
