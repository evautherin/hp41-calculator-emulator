# Quick Task 260603-s17: Mnemonic Fidelity — CLΣ + CLRALPHA

Follow-up to [[260603-lu0]] (the All Functions index). Two HP-41 mnemonic-fidelity
cleanups the index surfaced.

## Fix 1 — CL SIGMA → CLΣ (clear statistics registers)
The authentic mnemonic is **CLΣ** (CL + Σ, U+03A3). The resolver (`builtin_card_op`,
`"CL SIGMA" | "CL\u{03A3}" | "CLSIGMA"`) and BOTH `op_display_name` mirrors already
used the glyph; only the JSON `display_name` (+ keyboard-shortcuts label + matrix doc)
still said "CL SIGMA". Changed those three (data only). `just docs-matrix` regenerated
the matrix; `just docs-matrix-check` green. XEQ "CLΣ" and tap-to-run already resolved.

## Fix 2 — hide CLRALPHA (legacy alias of CLA)
`Op::AlphaClear` (display "CLRALPHA") and `Op::Cla` (display "CLA") both clear the
ALPHA register; the real HP-41 has only **CLA**. AlphaClear is a v1.0 legacy variant
that MUST stay (enum + resolver arm + both mirrors) for save-file deserialization
(Pitfall 8 — code comments warn against consolidation). So instead of touching the
backend, the All Functions index now excludes it via `OVERLAY_HIDDEN_ALIASES =
{AlphaClear}` in help_data.ts (status stays the truthful "implemented"). The C1
completeness guardrail subtracts the same set so it stays green. CLRALPHA still
resolves for old programs/saves; the index shows CLA once.
