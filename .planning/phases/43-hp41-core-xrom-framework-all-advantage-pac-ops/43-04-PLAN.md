  <action>
    Implement the core LU decomposition infrastructure and the three flagship operations.

    Create a private `fn lu_decompose(data: &mut [f64], n: usize) -> Result<(Vec<usize>, f64), HpError>` that performs Gaussian elimination with partial pivoting on an n x n matrix stored row-major in `data`. Returns the permutation vector and the sign of the permutation (+1.0 or -1.0). Returns `HpError::Domain` if the matrix is singular (zero pivot after pivoting). Algorithm from Numerical Recipes Section 2.3, re-derived from first principles (not copied). ~80-100 lines.

    Create `fn lu_solve(lu_data: &[f64], perm: &[usize], b: &mut [f64], n: usize)` that forward-substitutes then back-substitutes to solve LUx = Pb. ~30 lines.

    **MDET** (ADV-MTX-20): Find matrix by ALPHA name. Validate square. Copy data to f64 working array (via HpNum::to_f64). Call `lu_decompose`. Determinant = product of diagonal * sign. Convert back to HpNum, push to X. LiftEffect::Enable.

    **MINV** (ADV-MTX-21): Find matrix by ALPHA name. Validate square. Copy to f64 working array. LU decompose. Solve n identity columns via lu_solve. Write results back to matrix data. In-place modification of the named matrix.

    **MSYS** (ADV-MTX-22): Read two matrix names — A from ALPHA and b from stack (or second name convention per OM). LU decompose A. Solve Ax=b. Write solution to result matrix or stack. Convention: A is named in ALPHA, b is a column vector named in a second ALPHA entry; result overwrites b. If single-variable (1x1), just divide.

    Add Free42 disclaim header. Every algorithm is independently derived from Numerical Recipes primary literature, NOT from Free42.
  </action>
