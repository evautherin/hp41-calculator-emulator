# Phase 52 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.
> Source: 52-RESEARCH.md `## Validation Architecture`.

---

## Test Infrastructure

| Property | Value |
|----------|-------|
| **Framework** | Rust built-in test (`cargo test`), driven via `just` recipes |
| **Config file** | none — workspace `Cargo.toml` test settings |
| **Quick run command** | `just test-core --test xmem_backward_compat` |
| **Full suite command** | `just test` |
| **Estimated runtime** | quick ~seconds · full suite ~minutes |

---

## Sampling Rate

- **After every task commit:** Run `just test-core --test xmem_backward_compat` (new tests, ~seconds)
- **After every plan wave:** Run `just test` (full suite)
- **Before `/gsd:verify-work`:** `just test && just docs-matrix-check && just lint` — all green
- **Max feedback latency:** ~60 seconds for the quick path
