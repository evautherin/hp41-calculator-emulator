Pool file format (VERIFIED via codebase inspection — the writeback MUST reproduce this exactly):
  - Outer array opens `[\n`; each object opens at 4-space indent `    {\n`
  - Object properties at 8-space indent `        "key": "value",\n`
  - Key order per object: op_variant, display_name, category, status, phase, key_path,
    description, [example,] [notes,] [divergences,] [xrom]  — search_aliases APPENDED last
  - Non-ASCII present un-escaped today: Σ (hp41cv), — and … (time); generated umlauts (ä ö ü Ä Ö Ü ß) stay literal
  - File ends with a single trailing newline
  - Current total ≈ 131 KB across six pools (hp41cv 44 KB, math1 18 KB, stat1 11 KB, time 14 KB, advantage 42 KB, xmem 4 KB)

claude CLI (VERIFIED: /Users/daniel/.local/bin/claude v2.1.165):
  Invocation: claude -p --output-format json --max-turns 1 --bare --dangerously-skip-permissions --model sonnet "<prompt>"
  Envelope returned on stdout: {"type":"result","result":"<assistant text>", ...}
  Two-pass parse: serde_json::from_slice(&stdout) -> envelope; envelope["result"].as_str() -> inner;
                  strip_fences(inner); serde_json::from_str(inner) -> {"OpVariant": ["alias", ...], ...}
  Retry: up to 3 attempts, 2-second delay, on non-zero exit OR unparseable JSON; report (never silently drop) on final failure.
  NOTE (Wave-2 open question, do NOT resolve here): whether --bare breaks local OAuth auth is tested at the START of Wave 2, not in this plan's tests.

serde_json minimal-diff approach (D-60.4, RESEARCH Pitfall 1+2):
  - Cargo.toml: serde_json = { version = "1", features = ["preserve_order"] }  -> Value::Object backed by IndexMap (insertion order kept)
  - Custom Formatter wrapping PrettyFormatter::with_indent(b"    ") that overrides write_string_fragment
    to emit non-ASCII bytes literally instead of \uXXXX. (Fallback if Formatter delegation proves >50 LOC:
    to_string_pretty + a \uXXXX -> UTF-8 post-pass. Keep roundtrip_identity / utf8_unescaped tests as the gate either way.)

Fill-only contract (D-60.2):
  needs_aliases(entry) == true  iff  entry["search_aliases"] is None | empty array | malformed.
  insert_aliases appends "search_aliases" key (IndexMap append == last position).

Sibling template (scripts/docs-matrix/) — copy the Cargo.toml [workspace] stanza, publish=false, [[bin]], serde deps.
  IMPORTANT divergence: docs-matrix reads JSON -> writes Markdown (different out file). help-aliases is IN-PLACE
  (reads and writes the SAME pool path). Do NOT copy docs-matrix's two-arg in!=out shape (RESEARCH Pitfall 6).
