<objective>
Establish the iOS shared infrastructure every later Phase-55 plan depends on:
the `is_ios` platform-detection command (D-55.1), the `tauri-plugin-haptics`

gateway wave — all other plans (02–05) depend on it.

Output: `is_ios` command + permission + capability entry, haptics plugin
registration + Cargo dep, `isIos` state in App.tsx, `viewport-fit=cover`,
portrait-only orientation in both project.yml and Info.plist.
