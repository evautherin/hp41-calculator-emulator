<objective>
Make the calculator fully operable by touch for text entry: ALPHA-register input
AND modal name/label prompts (FUNCTION NAME? / LBL / XEQ / GTO / CLP / ASN), via an
on-screen `<input>` bar that stays above the iOS software keyboard.

Purpose: TOUCH-04 plus the D-55.2 scope correction. Without modal-label touch
entry, the FUNCTION NAME? / LBL / XEQ / GTO / CLP / ASN prompts would be impossible
to complete on an iPhone (no hardware keyboard), so the phase goal ("fully operable
by touch") would not be met. The component routes through the EXISTING dispatch
paths (alpha_<X> and submit_modal_with_label) rather than reinventing them.

Output: AlphaTouchInput.tsx (+ test), its CSS in App.css, and the iOS-gated render
+ prop wiring in App.tsx.
</objective>
