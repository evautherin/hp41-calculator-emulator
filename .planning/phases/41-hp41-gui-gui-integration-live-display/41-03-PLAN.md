| event_buffer -> dispatch_op | alarm:xeq:{label} triggers XEQ by name; label string originates from user-set alarm entries in CalcState |

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-41-06 | Spoofing | alarm:xeq:{label} event triggers arbitrary XEQ | accept | label comes from user-created alarm entries stored in CalcState; same trust level as manual XEQ input; xeq_by_name_local_resolve validates label |
