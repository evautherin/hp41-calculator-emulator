<objective>
Extend the hp41-core .raw codec with multi-program archive support and add comprehensive tests.

Purpose: RAW-03 requires importing multi-program .raw archives (community files from V41/Free42 often concatenate programs). The existing decode_program explicitly rejects trailing bytes after the END marker. A new decode_all_programs function splits the byte stream at END markers and decodes each segment independently. picker_label extracts the first LBL name for the multi-program picker UI (D-50.5).

Output: decode_all_programs and DecodedProgram in raw.rs, re-exported from cardreader/mod.rs, with integration tests covering single/multi/empty/truncated/XROM round-trip cases.
</objective>

  <action>
    Add three public items to hp41-core/src/cardreader/raw.rs after the existing decode_program function:

    1. DecodedProgram struct with fields: ops (Vec of Op), byte_len (usize). Derive Debug, Clone.

    2. decode_all_programs function that takes a byte slice and returns Result of Vec of DecodedProgram. Logic: iterate from offset 0, find END_MARKER via windows(3).position(), slice the segment from current offset to end_pos + 3, call decode_program on the segment (which expects exactly one END marker with no trailing bytes -- the slice guarantees this), push DecodedProgram with ops and byte_len. Cap at 256 iterations to prevent memory exhaustion from crafted inputs (return HpError::CardData if exceeded). Empty input returns Ok(empty Vec).

    3. picker_label function that takes program_index (usize), ops slice, and byte_len (usize), returns String. Find the first Op::Lbl(name) in ops, format as "NAME (N bytes)"; fall back to "Program {index+1} (N bytes)" if no LBL found. Per D-50.5.

    Update hp41-core/src/cardreader/mod.rs to add re-exports: pub use raw::{decode_all_programs, DecodedProgram, picker_label} alongside the existing pub use raw::{decode_program, encode_program} line.

    Make END_MARKER pub(crate) so tests can reference it if needed (currently it is private const).

    Error messages must follow the existing HpError::CardData(format!(...)) pattern from raw.rs.
  </action>
