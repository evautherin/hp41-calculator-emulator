## Phase Details

### Phase 53: Build-Approach Decision + iOS Scaffold Spike
**Goal**: The iOS build approach is decided and the app runs on both the Simulator and a physical device with one key dispatching through the engine
**Requirements**: BUILD-01..04 — Approach A (Tauri v2 Mobile) confirmed; ADR `docs/adr/v4.1-002-build-approach.md`; bundle ID `ch.talent-factory.hp41` registered. 4 plans.

### Phase 54: iOS Persistence Layer
**Goal**: Calculator state saved/restored inside the iOS sandbox with no desktop regression
**Requirements**: PERSIST-01..03 — AppHandle-aware path resolvers; `visibilitychange` autosave; device round-trip verified; serde backward-compat preserved. 3 plans.

### Phase 55: Touch UI Adaptation
**Goal**: Fully touch-operable on iPhone with native feedback and form-factor-aware layout
**Requirements**: TOUCH-01..11 — 44pt hit targets, safe-area, tap-delay elimination, keypad-only ALPHA entry, haptic tiers + error haptic, audio resume, bottom sheets, collapsible stack, overscroll suppression. 6 plans (verified on iPhone 15 Pro).

### Phase 56: App Lifecycle + Clock
**Goal**: WKWebView not fully suspended on brief backgrounding; clock correct on foreground return
**Requirements**: LIFE-01..02 — `tauri.ios.conf.json` `backgroundThrottling`; gated foreground `tick_time`; touch R/S stopwatch parity. 1 plan.

### Phase 57: Signing + TestFlight Pipeline
**Goal**: A signed IPA is produced by CI and distributed to testers via TestFlight internal distribution
**Requirements**: SHIP-01..05 — `PrivacyInfo.xcprivacy`; app icon + branded launch screen; `ci-ios.yml` `workflow_dispatch` (D-57.4 supersedes "on push to main"); signed IPA via **manual signing** (cert+profile created via ASC API; Xcode-26 `-allowProvisioningUpdates` 401 worked around); TestFlight upload (local + green CI run 26950247621) + on-device install. SHIP-02 privacy-manifest **bundle-wiring deferred** as tracked tech debt (non-blocking for internal TestFlight; required before public App Store). 4 plans.
