## Icon Master Production

The 1024x1024 master was authored using:
1. SVG designed at `/tmp/hp41-icon.svg` — stylized HP-41 faceplate with LCD display, 5 gold A-E keys, numeric grid, operator keys, and ENTER key
2. Rasterized via `rsvg-convert -w 1024 -h 1024 /tmp/hp41-icon.svg -o /tmp/app-icon-raw.png`
3. Flattened to fully-opaque RGB via Pillow: `Image.new('RGB', ..., (26, 26, 26)).paste(im, ...)` → `app-icon-1024.png`
4. Verified: `sips -g pixelWidth -g pixelHeight -g hasAlpha app-icon-1024.png` → 1024 × 1024, hasAlpha: no

**Tauri issue #11578 (slot-miss):** All 18 slots were generated correctly in this run — no manual gap-fill was required.

**Note on plutil:** The macOS system `plutil` in Xcode 26 runs in "Swift mode" and rejects plain JSON files (exits 1 with "Unexpected character {"). This is an environment quirk — `plutil` was designed for .plist (XML/binary) format. `Contents.json` is a valid JSON file as generated by Tauri CLI and accepted by Xcode. Validated via `python3 -m json.tool` (exits 0).
