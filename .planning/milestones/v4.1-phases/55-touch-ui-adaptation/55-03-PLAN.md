| display string → error-haptic | display_str is produced by the validated Rust engine; frontend only string-matches it |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-05 | Tampering | haptic call arguments | accept | Haptic tier args are fixed literals ('light'/'medium'/'heavy'/'error') chosen by a pure classifier from KeyDef; no user-controlled value reaches the plugin |
| T-55-06 | Denial of Service | error-haptic re-fire on every render | mitigate | errorHapticFiredRef guard fires once per error transition and resets on clear (Pitfall 7); prevents haptic-buzz loop on clock ticks |

No new high-severity attack surface. Audio resume and haptics are local UI feedback; no network, no state mutation, no new input vector.
</threat_model>
