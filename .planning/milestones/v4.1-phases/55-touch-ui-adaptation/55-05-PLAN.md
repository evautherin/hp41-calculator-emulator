<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| UI render → CalcStateView | Bottom sheets and collapsible stack only READ existing CalcStateView fields (print lines, program_steps, pc, register strings); no new write path |
| user tap → sheet/chevron toggle | Toggles are local React state changes only; the "Clear" print action reuses the existing clear path |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-55-09 | Tampering | bottom-sheet / stack rendering | accept | Read-only presentation of already-validated CalcStateView fields; no new input crosses to Rust; local toggle state only |
| T-55-10 | Denial of Service | print-sheet "Clear" action | accept | Reuses the existing clear-print path (session-only buffer per UI-SPEC); no persisted data, easily regenerated; identical to desktop semantics |

No new high-severity attack surface: layout/presentation only, reading existing validated state.
</threat_model>
