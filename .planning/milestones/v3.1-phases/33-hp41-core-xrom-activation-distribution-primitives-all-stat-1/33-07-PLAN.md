## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| t-statistic ↔ beta_regularized_f64 argument mapping | The Student-t CDF formula uses I_{ν/(ν+t²)}(ν/2, ½). Reversing the (a, b) order or using x = t²/(ν+t²) instead of ν/(ν+t²) silently produces a wrong p-value that may even fall in the right neighborhood for some test data. |
| pooled vs Welch variance | SPEC.md Req. 25 LOCKS pooled; the unit test asserts the SPEC.md acceptance value to within 1e-7 — Welch would produce a different value for unequal-variance data, so the oracle catches drift. |
