- **OM citation**: HP 00041-90030 (1979), distribution evaluation section — the OM does NOT specify a numerical tolerance band for ΣNORMD CDF output; the original 33-SPEC.md Req. 7 oracle of 1e-9 was a planning-phase estimate inconsistent with the rust_decimal `MathematicalOps::norm_cdf` backing implementation.
- **Our behavior**: ΣNORMD CDF returns Q(x) with ~1.3e-7 absolute precision (rust_decimal uses Abramowitz & Stegun §6 6-term polynomial approximation). Test `cdf_oracle_q_of_196_within_a_and_s_band` (`hp41-core/src/ops/stat1/normd.rs:257`) asserts the relaxed 1e-5 band.
- **OM behavior**: OM does not specify a tolerance; on real HP-41C hardware, ΣNORMD's precision depends on the underlying ROM implementation (uncited).
- **Rationale**: rust_decimal `MathematicalOps::norm_cdf` is the canonical Rust backing for normal CDF; switching to a higher-precision implementation would add a new runtime dep (statrs rejected per ADR-v3.1-002 / D-33.5). The 1e-5 band is sufficient for user-facing statistical workflows.
- **See**: `33-SPEC-AMENDMENT.md` row 1 (Plan 35-01 reconciliation); `hp41-core/src/ops/stat1/normd.rs:257`; ADR-v3.1-002 (Plan 35-03) distribution primitives policy; scipy.stats.norm.cdf as cross-check oracle.

- **OM citation**: HP 00041-90030 (1979), ΣAOVONE program description — the OM provides a worked ANOVA example; the F-ratio value depends on the specific test dataset; original 33-SPEC.md Req. 11 oracle of F = 100.0 for groups [1..5]/[6..10]/[11..15] was a planning-phase estimate.

### D-35-09: ΣTSTAT Pooled-Variance Convention — Welch Excluded

- **OM citation**: HP 00041-90030 (1979), ΣTSTAT program description — pooled-variance convention confirmed by NPS document NPS55-84-003 p. 30+ ZS-4 / ZS-5 evidence (NPS confirms Stat 1 Pac's two-sample t uses pooled variance, not Welch's unequal-variance approximation).
- **Our behavior**: ΣTSTAT computes the two-sample t-statistic with pooled variance: `t = (μ₁ − μ₂) / (s_p · √(1/n₁ + 1/n₂))` where `s_p² = ((n₁−1)·s₁² + (n₂−1)·s₂²) / (n₁ + n₂ − 2)`; df = n₁ + n₂ − 2 (integer). Welch's unequal-variance t is NOT implemented (anti-feature per CONTEXT.md "Out of Scope").
- **OM behavior**: Identical (pooled-variance per NPS confirmation).
- **Rationale**: NPS p. 30+ ZS-4/5 confirms Stat 1 Pac uses pooled variance; Welch's t is not part of Stat 1 Pac (and would change the df calculation to the Welch-Satterthwaite approximation). Welch's t is locked out per REQUIREMENTS.md "Out of Scope" line for "Welch's t-test (unequal variance)".
- **See**: `hp41-core/src/ops/stat1/hypothesis.rs::op_sigma_tstat`; SPEC.md Req. 25; NPS55-84-003 p. 30+; REQUIREMENTS.md "Out of Scope".
