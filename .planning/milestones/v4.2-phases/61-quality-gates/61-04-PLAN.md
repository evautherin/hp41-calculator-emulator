Add the schema-only CI gate (HSQUAL-03): a bash+jq script `scripts/check-aliases-schema.sh`
modeled on the existing `scripts/check-free42-contamination.sh` precedent, wired via a new
`just schema-aliases-check` recipe (mirroring `just license-audit`) and a new `schema-aliases`
job in `.github/workflows/ci.yml` (mirroring the `license-audit` job). The gate enumerates
ALL SIX help pools EXPLICITLY in a `POOLS` array — never a `docs/hp41-*-functions.json` glob,

`search_aliases` is an array-of-strings where present and that every `status:"implemented"`
entry has >=1 alias, exiting non-zero on any violation. It is schema-only: it NEVER regenerates
and diffs (LLM output is non-deterministic — explicitly out of scope per REQUIREMENTS).

Purpose: a permanent CI tripwire against alias-schema regressions across all six pools.
Output: one new script, one Justfile recipe, one ci.yml job. `just schema-aliases-check` green.
