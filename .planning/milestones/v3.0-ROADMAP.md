## Overview

Behavioral emulation of the HP-41C **Math Pac I** (HP part number 00041-90034, Owner's Manual 1979) as the first XROM application module — 10 prompt-driven workflow programs with ~55 XEQ-by-name entry points, usable in CLI + GUI through a new modal-workflow layer that extends the v2.x built-in pattern, without HP-copyrighted ROM-image redistribution.

**Build sequence:** core (Phase 28) → cli (Phase 29) → docs (Phase 30) → gui (Phase 31) → tests (Phase 32). Phase numbering continued from v2.2 (Phase 27 was the last shipped phase).

**Scope boundary (locked 2026-05-16):**
- v3.0 = HP Math Pac I per Owner's Manual 00041-90034 only
- Advanced Matrix Pac (M+, MAT*, INV-transpose, V+, VDOT, …) → v3.2+
- Advantage Pac (PROOT, CABS, CARG, CCHS, CCONJ, Romberg-INTG, …) → v3.3+
- Stat 1 Pac → v3.1
- Time Pac → v3.2
- HP-copyrighted ROM-image redistribution remains permanently out of scope — we ship behavioral emulation of the documented functions, never ROM bytes.

## Milestone Summary

### Cross-cutting Constraints Preserved

- **SC-4 invariant** — no calculator logic duplication in `hp41-gui`; `op_display_name` remains the only documented exception. Math Pac I math lives entirely in `hp41-core/src/ops/math1/`.
- **No HP-copyrighted ROM bytes** — behavioral emulation only. Per-file disclaim header in every `hp41-core/src/ops/math1/*.rs`. CI gate `scripts/check-free42-contamination.sh` enforces a 12-distinctive-symbol Free42 / Intel BID / decNumber / GPL/AGPL grep + per-file header presence; runs in `just license-audit` plus dedicated `.github/workflows/ci.yml::license-audit` parallel job.
- **`#![deny(clippy::unwrap_used)]`** held across `hp41-core`. Test modules carry `#[allow(clippy::unwrap_used)]` at file scope.
- **`#[serde(default)]`** on every new `CalcState` field (`xrom_modules`, `complex_mode`, `matrix_dim`, `matrix_active_reg`, `modal_program`, `integ_state`, `solve_state`, `cancel_requested`). Transient fields additionally `#[serde(skip)]`. v1.0–v3.0 save files load without migration.
- **4-exhaustive-match invariant** — every new `Op` variant lands in `dispatch()` (ops/mod.rs) + `execute_op()` (ops/program.rs) + both `prgm_display.rs` (CLI + GUI). Compile-time exhaustive matches block missing arms. `math1_op_test_count.rs` + `xrom_shadowing.rs` cross-check 45 `Op` variants × 14 test files + 52 `MATH_1.ops` × 18-entry allowlist.
- **CLI ↔ GUI parity (D-25.6)** — every new Math Pac I function reachable in both surfaces through the shared `xrom_resolve` in `hp41-core`; no frontend-only resolver paths.
- **MSRV 1.88** unchanged. Zero new runtime dependencies in `hp41-core`. One dev-dependency added: `approx 0.5.1` (relative-tolerance assertion macros for matrix/complex tests).

### Key Decisions

| ID | Decision | Rationale |
|----|----------|-----------|
| ADR-001 | Op-strategy A (one `Op` variant per Math Pac I function) | Preserves 4-exhaustive-match invariant; rejects `Op::XromCall(u16)` table dispatch |
| ADR-002 | User-callback re-entrancy: strict-reject nested INTG/SOLVE/DIFEQ | Matches Math Pac I hardware behavior per OM; simplest invariant; verbatim Free42 disclaim |
| ADR-003 | INV-EPSILON value transcribed from OM | Resolves community-vs-OM ambiguity (Pitfall 7); OM-cited |

### Issues Resolved

- **Pitfall 1 (function-name collision):** `xrom_resolve` fires LAST in resolver chain; `tests/xrom_shadowing.rs` + `tests/xrom_chain_order.rs` CI gates
- **Pitfall 2 (INTG threshold):** tied to `DisplayMode`, OM-cited (ADR-004)
- **Pitfall 4 (user-callback re-entrancy):** `run_loop` (NOT `run_program`) re-entry; nested INTG/SOLVE/DIFEQ rejected per XROM-08
- **Pitfall 5 (POLY clustering):** multiplicity-as-cluster convention documented in `docs/hp41-math1-divergences.md`
- **Pitfall 6 (complex branch cuts):** `complex_atan2(0,0)→0` first arm; zero-divisor branch BEFORE division in `Op::CDiv`
- **Pitfall 7 (INV EPSILON):** OM transcription done before Plan 28-06 landed (ADR-003)
- **Pitfall 11 (GUI freeze on long INTG):** cancellation channel `Arc<AtomicBool>` + per-64-samples lock release; `request_cancel` Tauri command
- **Pitfall 14 (cross-platform drift):** relative tolerance 1e-7 documented as Math Pac I floor; criterion benchmarks pinned to ubuntu-latest
- **Pitfall 17 (assertion discipline):** `tests/lint_math1_assertions.rs` blocks `assert_eq!(decimal, decimal)` on iterated results
- **Pitfall 18 (citation provenance):** every divergence-doc entry and ADR cites OM page-and-example, MoHPC URL, or Mike Sebastian forensic page
- **Pitfall 19 (Free42 GPL contamination):** per-file header policy + CI gate `scripts/check-free42-contamination.sh` (12-symbol grep) wired into `just ci` and `.github/workflows/ci.yml::license-audit`
- **Pitfall 21 (Tauri permissions):** `request_cancel` permission TOML at `hp41-gui/src-tauri/permissions/request-cancel.toml`
