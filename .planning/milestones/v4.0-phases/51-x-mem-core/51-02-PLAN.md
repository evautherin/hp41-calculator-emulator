## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ALPHA register / X register → X-MEM op | User-controlled file name (alpha_reg) and register index (stack.x) cross into op logic |
| XmemFile.data: Vec<u8> → decode_program / decode_data | Stored bytes (possibly from a tampered save file) are decoded by an op |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
