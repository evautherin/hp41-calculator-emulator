<objective>
Add CLI flags for .raw and .card.json import/export with stdin/stdout piping support and --batch mode.

Purpose: RAW-06 requires CLI users to import/export programs and data via command-line flags. This enables scripting workflows like `curl https://example.com/program.raw | hp41 --import-raw - --batch` for automated loading. The flags follow Unix conventions: file path argument or `-` for stdin/stdout.

Output: 5 new clap flags (--import-raw, --export-raw, --import-data, --export-data, --batch) in hp41-cli/src/main.rs with startup processing before the TUI launches.
</objective>

    read_file_or_stdin(path: &str) -> std::io::Result of Vec of u8: if path == "-", read all bytes from std::io::stdin() via Read::read_to_end. Otherwise std::fs::read(path).

    Export data: if let Some(ref data_path) = cli.export_data, capture_data_card(&initial_state), encode_data, write via write_file_or_stdout. Print to stderr "Saved data card".

    4. After all import/export processing, add the --batch early-exit:

    use hp41_core::cardreader::{insert_program_ops, capture_data_card, load_data_card, decode_data, encode_data};
