## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Frontend -> set_pref IPC | Untrusted string value for onboarding_done key |
| Frontend -> save_state IPC | User-triggered disk I/O |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-01 | Tampering | set_pref onboarding_done | mitigate | Parse `value == "true"` -> bool coercion; any non-"true" value becomes false. Unknown keys rejected by existing `_ => Err(...)` arm (T-48-01 extension). |
| T-49-02 | DoS | save_state rapid invocation | accept | User-initiated only (Ctrl+S / F5). No programmatic call path. Disk I/O is bounded by OS file system. |
| T-49-03 | Tampering | keyboard-shortcuts.json | mitigate | Vite static JSON-import fails build on malformed JSON (build-blocker semantics). JSON is bundled at build time, not fetched at runtime. |
| T-49-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed in this phase. Zero new runtime deps policy maintained. |
</threat_model>
