Each entry is a JSON object with these existing fields:
  op_variant: string (PascalCase)
  display_name: string (HP-41 mnemonic)
  category: string
  status: "implemented" | "deferred-v3" | "na"
  phase: string | null
  key_path: string | null
  description: string
  divergences?: string[] (optional)
  xrom?: { module: string, module_id: number, function_id: number } (optional, XROM entries only)

Phase 49 adds two optional fields (D-49.5):
  example?: string  — e.g. "3 ENTER 4 + -> 7"
  notes?: string    — e.g. "Stack lift enabled; T register lost"

Both fields are optional. Entries without them stay in current compact format.
