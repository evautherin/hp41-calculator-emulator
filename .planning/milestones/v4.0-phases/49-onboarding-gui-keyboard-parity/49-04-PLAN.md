<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Physical keyboard -> resolveKeyId | Ctrl+key combos dispatching ops |
| resolveKeyId -> handleKey | __save_state__ special key ID must not reach dispatch_op |
| Frontend -> set_pref IPC | onboarding_done value |
| Frontend -> save_state IPC | Manual save invocation |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-49-07 | Tampering | resolveKeyId Ctrl+key | mitigate | Ctrl+key check FIRST in resolveKeyId; return null for unknown Ctrl combos (no fall-through to letter map) |
| T-49-08 | Tampering | __save_state__ leak | mitigate | Intercept __save_state__ in handleKey BEFORE dispatchKeyId; never let it reach key_map.rs (which would error on unknown key) |
| T-49-09 | Denial of Service | F5 browser reload | mitigate | e.preventDefault() called when F5 detected; prevents Tauri WebView from reloading |
| T-49-10 | Denial of Service | Ctrl+S browser save | mitigate | e.preventDefault() called when Ctrl+S detected; prevents browser save-page dialog |
| T-49-SC | Tampering | npm/pip/cargo installs | mitigate | No new packages installed. Zero new runtime deps policy maintained. |
</threat_model>
