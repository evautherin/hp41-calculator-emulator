<objective>

They use the host system clock (D-38.1) with a user-adjustable offset (D-38.2) to deliver HP-41CX-faithful time/date retrieval. The "pull on redraw" architecture (D-carried.7) means these ops just compute results on-demand -- no background threads.
Output: Fully-implemented clock.rs replacing Wave 1 stubs; all clock operation tests pass.
