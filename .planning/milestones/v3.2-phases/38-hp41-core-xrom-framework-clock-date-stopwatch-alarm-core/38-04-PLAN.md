  <behavior>
    - op_runsw: from Idle -> Running (stopwatch_start = Some(Instant::now()))
    - op_runsw: from Stopped -> Running (resumes; start captures now, accumulated preserved)
    - op_stopsw: from Running -> Stopped (elapsed += start.elapsed(), start = None)
    - op_stopsw: from Idle or Stopped -> no-op (remains in current state)
    - op_setsw: initializes stopwatch from X register (HH.MMSSss -> accumulated seconds)
    - op_rclsw when Running: returns accumulated + (now - start) as HH.MMSScc
    - op_rclsw when Stopped/Idle: returns accumulated as HH.MMSScc
    - op_stpw: records current elapsed into stopwatch_split (split while running continues)
    - op_swpt: recalls stopwatch_split to X register
    - op_sw: sets stopwatch_keyboard_mode = true (Phase 39/41 wire keyboard redefinition)
    - Stopwatch uses Instant (monotonic) per D-38.7 / TIME-SW-09
  </behavior>
  <action>
    Replace the stub content of `stopwatch.rs` with full implementations. Keep the Free42 disclaim header and the `StopwatchMode` enum + Default impl.

    Add imports: `std::time::Instant`, `crate::error::HpError`, `crate::num::HpNum`, `crate::stack::{apply_lift_effect, enter_number, LiftEffect}`, `crate::state::CalcState`, `super::date_arith::{parse_time_hpnum, secs_to_hpnum_time}`.

    Implement private helper `fn current_elapsed(state: &CalcState) -> f64`: If `stopwatch_mode == Running` and `stopwatch_start.is_some()`, return `state.stopwatch_accumulated + state.stopwatch_start.unwrap_or_else(Instant::now).elapsed().as_secs_f64()`. Otherwise return `state.stopwatch_accumulated`. (Note: in production code, use `unwrap_or_else` per clippy deny rule.)

    Implement `op_runsw(state)`: Set `stopwatch_mode = Running`. Set `stopwatch_start = Some(Instant::now())`. `apply_lift_effect(Neutral)`. If already Running, this is a no-op (already started).

    Implement `op_stopsw(state)`: If `stopwatch_mode == Running`, compute elapsed since `stopwatch_start` via `.elapsed().as_secs_f64()`, add to `stopwatch_accumulated`, set `stopwatch_start = None`, set `stopwatch_mode = Stopped`. Otherwise no-op. `apply_lift_effect(Neutral)`.

    Implement `op_setsw(state)`: Parse X register as HH.MMSSss via `parse_time_hpnum`. Convert to total seconds: `hours*3600 + minutes*60 + seconds + centis*0.01`. Write to `stopwatch_accumulated`. Set `stopwatch_mode = Stopped` (ready to RUNSW). Clear `stopwatch_start = None`. `apply_lift_effect(Neutral)`.

    Implement `op_rclsw(state)`: Compute total elapsed via `current_elapsed(state)`. Convert to HH.MMSScc via `secs_to_hpnum_time`. Push to X with `enter_number` + `apply_lift_effect(Enable)`.

    Implement `op_stpw(state)`: Record current elapsed into `stopwatch_split = current_elapsed(state)`. Stopwatch continues running (does not stop). `apply_lift_effect(Neutral)`.

    Implement `op_swpt(state)`: Push `stopwatch_split` converted via `secs_to_hpnum_time` to X. `enter_number` + `apply_lift_effect(Enable)`.

    Implement `op_sw(state)`: Set `state.stopwatch_keyboard_mode = true`. This enables the interactive stopwatch mode; the actual keyboard redefinition is Phase 39 (CLI) / Phase 41 (GUI) scope. `apply_lift_effect(Neutral)`.

    Also implement `pub fn get_stopwatch_display_str(state: &CalcState) -> Option<String>` for Phase 39/41 frontend use (per TIME-SW-08): If `stopwatch_keyboard_mode` is true, compute `current_elapsed(state)` and format as "HH:MM:SS.cc". Returns None if not in stopwatch mode.

    Add comprehensive `#[cfg(test)] mod tests`. For timing-dependent tests, use `std::thread::sleep(Duration::from_millis(50))` between RUNSW and STOPSW to verify elapsed > 0. Test all state transitions.
