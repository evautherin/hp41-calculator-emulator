    Implement `submit_step(state: &mut CalcState, step: TimeStep) -> Result<(), HpError>`:

    For `SetTimePrompt` (per D-38.2 / Pitfall 7):
    1. Clear modal: `state.modal_program = None; state.modal_prompt = None;`
    2. Read X register. Handle PM shorthand: if X is negative and in range [-1, -11], convert to equivalent positive time (e.g., -2 -> 14.000000). Use `HpNum::is_sign_negative()` check.
    3. Parse X as HH.MMSSss via `parse_time_hpnum`.
    4. Compute entered_seconds: `hours*3600 + minutes*60 + seconds` (as i64).
    5. Get current local time seconds: read `SystemTime::now()`, apply existing `state.time_offset_secs`, decompose to local, compute current_seconds = `cur_h*3600 + cur_m*60 + cur_s`.
    6. Compute delta: `entered_seconds - current_seconds` (as i64).
    7. Update `state.time_offset_secs += delta`.
    8. Return Ok(()).

    For `SetDatePrompt`:
    1. Clear modal.
    2. Parse X as date via `parse_date_hpnum(&state.stack.x, state.flags & (1 << 31) != 0)`.
    3. Compute entered JDN via `date_to_jdn(year, month, day)`.
    4. Get current local date, compute current JDN.
    5. Compute day_delta: `entered_jdn - current_jdn` (i64).
    6. Update `state.time_offset_secs += day_delta * 86400`.
    7. Return Ok(()).

    For `XyzalmTimePrompt`:
    1. Clear modal.
    2. Return Ok(()) -- multi-step XYZALM modal is handled directly in op_xyzalm for v3.2 (the XYZALM op reads all stack registers at once without a multi-step modal per QRC stack layout; the prompt variant exists as forward-compatibility for a future interactive mode).
