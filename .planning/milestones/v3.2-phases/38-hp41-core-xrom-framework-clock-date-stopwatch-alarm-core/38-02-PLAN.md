    `op_date_plus(state)`: Read Y register as date via `parse_date_hpnum(&state.stack.y, dmy)` where `dmy = state.flags & (1 << 31) != 0`. Read X register as integer days count (truncate to i64). Convert Y-date to JDN, add days, convert back to (year, month, day), format as HpNum in the same MDY/DMY format, push result to X using `enter_number` + `apply_lift_effect(Enable)`. Drop stack (Y consumed). Use standard binary-result stack behavior: X <- result, Y <- Z, Z <- T, T <- T, LASTX <- old_X.

    `op_dmy(state)`: Set Flag 31: `state.flags |= 1 << 31`. Apply `LiftEffect::Neutral`. Return Ok(()).

    `op_mdy(state)`: Clear Flag 31: `state.flags &= !(1 << 31)`. Apply `LiftEffect::Neutral`. Return Ok(()).
