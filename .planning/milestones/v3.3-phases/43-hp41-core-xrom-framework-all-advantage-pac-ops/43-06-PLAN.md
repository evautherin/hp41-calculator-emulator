  <behavior>

    - Test: DS subtracts data point from accumulation (inverse of AS)
    - Test: FIT after 3 linear points returns correct slope/intercept
    - Test: Y?X predicts Y from X using current fit coefficients
    - Test: SZ? returns true (1) if enough data points, false (0) otherwise
    - Test: BFIT selects best model (linear/log/exp/power) by correlation
    - Test: CFIT master workflow initializes fit
  </behavior>
  <action>
    Replace all 7 stubs in curve_fit.rs.

    Curve fitting uses storage registers for accumulation (Sigma-x, Sigma-y, Sigma-x^2, Sigma-xy, Sigma-y^2, n). The Advantage Pac curve fit extends the Stat 1 Pac pattern but operates on a separate set of accumulation registers to avoid conflict.

    Use registers R10-R19 (or a suitable contiguous block that does not overlap with existing Stat 1 Pac or Math Pac I register conventions) for curve-fit accumulation: R10=n, R11=Sigma-x, R12=Sigma-y, R13=Sigma-x^2, R14=Sigma-xy, R15=Sigma-y^2, R16=current_model (0=linear, 1=log, 2=exp, 3=power), R17=coefficient_a, R18=coefficient_b, R19=correlation_r. Define named constants for all register indices at the top of the file.

    **CFIT** (ADV-MATH-27): Initialize curve fit — clear accumulation registers R10-R19. Set model to linear (0). LiftEffect::Neutral.

    **AS** (ADV-MATH-28): Add data point — read (X=x, Y=y) from stack. Accumulate: n++, Sigma-x += x, Sigma-y += y, Sigma-x^2 += x^2, Sigma-xy += x*y, Sigma-y^2 += y^2. Apply log/exp/power transforms based on current model if needed. Stack drops Y.

    **DS** (ADV-MATH-29): Delete data point — inverse of AS (subtract contributions). Stack drops Y.

    **BFIT** (ADV-MATH-30): Best fit selection — compute correlation r for each of the 4 models (linear, logarithmic, exponential, power), select the model with highest |r|, store model index in R16. Push |r| to X.

    **FIT** (ADV-MATH-31): Compute fit coefficients a, b for current model: y = a + bx (linear), y = a + b*ln(x) (log), y = a*exp(bx) (exp), y = a*x^b (power). Store in R17, R18. Push b to Y, a to X.

    **Y?X** (ADV-MATH-32): Predict Y from X using stored coefficients and current model. Read X from stack, compute predicted y, push to X. LiftEffect::Enable.

    **SZ?** (ADV-MATH-33): Test if n >= 3 (minimum for meaningful fit). Push 1 to X if sufficient, 0 otherwise.

    Write tests covering the linear fit case end-to-end (CFIT, AS 3 points, FIT, Y?X prediction).
  </action>

  </verify>

  <action>
    Replace all 14 stubs in vectors.rs.

    Vectors are stored in three contiguous registers per the OM convention. Use registers R20-R22 for vector A, R23-R25 for vector B, R26-R28 for result vector. Define named constants: `VEC_A_BASE: u8 = 20`, `VEC_B_BASE: u8 = 23`, `VEC_RESULT_BASE: u8 = 26`.

    Helper: `fn read_vec(state: &CalcState, base: u8) -> (f64, f64, f64)` reads 3 components from registers. `fn write_vec(state: &mut CalcState, base: u8, v: (f64, f64, f64))` writes 3 components.

    **VE** (ADV-MATH-41): Vector entry — modal prompt to enter 3 components. Set `modal_program = Some(ModalProgram::Advantage(AdvantageStep::VeComponentPrompt(0)))` and `modal_prompt`. Each R/S submit stores one component. After 3, vector is in registers.

    **V+** (ADV-MATH-34): Read vectors A and B from registers, compute element-wise sum, store in result registers.

    **V-** (ADV-MATH-35): Element-wise subtraction A - B.

    **DOT** (ADV-MATH-36): Dot product of A and B. Push scalar result to X. LiftEffect::Enable.

    **CROSS** (ADV-MATH-37): Cross product of A and B. Store result in result registers. Push magnitude to X.

    **VC** (ADV-MATH-38): Alias for CROSS (alternate entry point per OM).

    **VS** (ADV-MATH-39): Scalar multiply — read scalar from X, multiply vector A by scalar, store in result registers.

    **VR** (ADV-MATH-40): Recall result vector — push components to X, Y, Z stack registers.

    **VXY** (ADV-MATH-42): Project vector to X-Y plane (zero the Z component).

    **UV** (ADV-MATH-43): Unit vector — normalize vector A to magnitude 1.

    **V<** (ADV-MATH-44): Vector magnitude = sqrt(a1^2 + a2^2 + a3^2). Push to X.

    **VD** (ADV-MATH-45): Alias for DOT (alternate entry point).

    **V*** (ADV-MATH-46): Alias for VS (alternate entry point).

    **TR** (ADV-MATH-47): Coordinate transformation — apply rotation/translation per OM §3 convention. Read transformation parameters from stack/registers.

    Write tests for DOT, CROSS, V+, V-, VS, UV, V< as core verifiable behaviors.
  </action>
