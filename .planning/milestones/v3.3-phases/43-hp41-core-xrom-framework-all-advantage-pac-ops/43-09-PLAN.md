    **\*I** (ADV-TVM-06): Solve for periodic interest rate using Newton-Raphson iteration.

    TVM equation (END mode, annuity-immediate):
    `f(i) = PV + PMT * (1 - (1+i)^(-N)) / i + FV * (1+i)^(-N) = 0`

    Derivative:
    `f'(i) = PMT * [(1-(1+i)^(-N))/i^2 - N*(1+i)^(-N-1)/i] - N*FV*(1+i)^(-N-1)`

    BEGIN mode (annuity-due) adjusts PMT term by multiplying by (1+i).

    Newton iteration: `i_new = i_old - f(i_old) / f'(i_old)`. Start with initial guess i = 0.1 (10%). Converge when `|i_new - i_old| < TVM_CONVERGENCE_THRESHOLD`. Max TVM_MAX_ITERATIONS = 100 iterations.

    On convergence: store `i` as `tvm.i`, push `i * 100` (percent) to X. LiftEffect::Enable.
    On non-convergence (D-43.13): push last iterate to X, push "NO SOLUTION" to print_buffer, return `HpError::NoRoot`.

    Special case: if N=0, return HpError::Domain. If i=0 (zero rate), use the limit form: PV + PMT*N + FV = 0 → solve directly.

    Add serde round-trip test: serialize a TvmState with non-default values, deserialize, verify all fields preserved (confirms D-43.11: no serde(skip)).

    Write comprehensive unit tests.
