    Replace all 12 stub functions in conv.rs with full implementations.

    Add a helper `fn x_to_u64_masked(x: &HpNum) -> Result<u64, HpError>` that converts HpNum to f64, rounds to integer, takes absolute value, and masks to `ADV_WORD_MASK` (36-bit). Return `HpError::Domain` if the value is NaN or > 2^53 (f64 integer precision limit). This helper is used by BINVIEW, HEXVIEW, CVTVIEW, NOT, AND, OR, XOR, ROTXY, BIT?.

    **BININ** (ADV-CONV-01): Read `state.alpha_reg.trim()`, reject empty with `HpError::Domain`, parse via `u64::from_str_radix(&s, 2)`, mask to `ADV_WORD_MASK`, convert to `HpNum`, `apply_lift_effect(Enable)`, set `stack.x`. Same pattern for **OCTIN** (radix 8, ADV-CONV-03) and **HEXIN** (radix 16, ADV-CONV-05).

    **BINVIEW** (ADV-CONV-02): `x_to_u64_masked`, format as `format!("{:b}", val)`, push to `state.print_buffer`, also write binary string to `state.alpha_reg`. LiftEffect::Neutral. Same display pattern for **HEXVIEW** (ADV-CONV-06, format `{:X}`).

    **CVTVIEW** (ADV-CONV-04): `x_to_u64_masked`, format in all 4 bases (BIN/OCT/DEC/HEX), push all 4 lines to `state.print_buffer`.

    **NOT** (ADV-CONV-07): `x_to_u64_masked`, XOR with `ADV_WORD_MASK`, convert back, `apply_lift_effect(Enable)`, set `stack.x`.

    **AND** (ADV-CONV-08): Pop X and Y as u64 masked, compute `x_val & y_val`, result to X, stack drops (Y consumed). Same binary pattern for **OR** (ADV-CONV-09, `|`), **XOR** (ADV-CONV-10, `^`).

    **ROTXY** (ADV-CONV-11): Pop X as the value and Y as the shift count. Positive Y = rotate left, negative Y = rotate right. Rotation is circular within 36 bits: `left = (val << (shift % 36)) | (val >> (36 - shift % 36))`, masked. Result to X, stack drops.

    **BIT?** (ADV-CONV-12): Read Y as bit number (0-35), X as value. Test `(x_val >> bit_num) & 1`. If set, result 1.0 to X and return `Ok(())`. If clear, result 0.0 to X and return `Ok(())`. The "skip" behavior follows the same conditional-test pattern as `Op::XEqZero` etc. — return true/false in X register (the CLI/program.rs layer handles the actual skip logic via `execute_op` returning skip signal OR the simpler approach of just pushing 1/0 to X and letting program-level comparisons handle it). Follow whichever pattern the existing bit-test / flag-test ops use.

    Include a unit test module at the bottom with `#[cfg(test)]` and `#[allow(clippy::unwrap_used)]`. Write tests for every behavior listed above.
