  <action>
    Replace all 5 stubs in matrix_complex.rs.

    Complex matrices store data interleaved: element (i,j) real part at `data[2*(i*cols+j)]`, imaginary part at `data[2*(i*cols+j)+1]`. The `is_complex` flag on AdvMatrix distinguishes complex from real matrices.

    **C<>C** (ADV-MTX-44): Exchange two named complex matrices. Read two names (first from ALPHA, second from a convention). Swap their data vectors.

    **CMAXAB** (ADV-MTX-45): Find maximum |z| = sqrt(re^2 + im^2) across all elements of the current complex matrix. Push result to X.

    **CNRM** (ADV-MTX-46): Complex matrix Frobenius norm = sqrt(sum of |z_ij|^2) for all elements.

    **CSUM** (ADV-MTX-47): Sum all complex elements. Push real sum to X, imaginary sum to Y. LiftEffect::Enable.

    **YC+C** (ADV-MTX-48): Add complex number (X+iY from stack) to the element at current I,J in the complex matrix. Modifies matrix in-place.

    All complex matrix ops validate `mat.is_complex == true`; return `HpError::Domain` if called on a real matrix.

    Write tests for all 5 operations.
  </action>
