    **SUM** (ADV-MTX-35): Sum all elements of current matrix. Push result to X. LiftEffect::Enable.

    **SUMAB** (ADV-MTX-36): Sum of absolute values of all elements. Push to X.

    **MAX/MIN** (ADV-MTX-37/38): Maximum/minimum element value. Push to X.

    **MAXAB** (ADV-MTX-39): Maximum absolute value element. Push to X.

    **RMAXAB** (ADV-MTX-40): Maximum absolute value in the current row (row = adv_matrix_i). Push to X.

    **FNRM** (ADV-MTX-41): Frobenius norm = sqrt(sum of squares of all elements). Convert each element to f64 via HpNum::to_f64(), compute, convert result back.

    **RNRM** (ADV-MTX-42): Row norm = max over all rows of (sum of absolute values in that row). Push to X.

    **RSUM** (ADV-MTX-43): Sum of current row's elements. Row selected by adv_matrix_i.

    **MSWAP** (ADV-MTX-30): Swap rows Y and X (1-indexed from stack, convert to 0-indexed). Both Y and X consumed from stack.

    **R<>R** (ADV-MTX-31): Exchange rows Y and X (same as MSWAP — alias or identical behavior per OM).

    **R>R?** (ADV-MTX-32): Compare rows k and l; conceptually sets skip flag if row k > row l in some defined ordering (e.g., first element comparison). Return 1 in X if true, 0 if false.

    **PIV** (ADV-MTX-33): Partial pivoting step — find the element with maximum absolute value in the current column (from current row to last row), swap that row with current row. Used as a building block for LU decomposition.

    **MP** (ADV-MTX-34): Matrix print — push all elements to print_buffer in row-major order, formatted as "R1C1= 1.234" etc.
