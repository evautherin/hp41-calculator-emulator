# Milestone v3.1: Stat 1 Pac Emulation

**Status:** ✅ SHIPPED 2026-05-24
**Phases:** 33–37
**Total Plans:** 23

## Overview

Behavioral emulation of the HP-41C **Stat 1 Pac** (HP part 00041-14001, OM 00041-90030, June 1979) as the second XROM application module — XROM ID 2 — mirroring the v3.0 Math Pac I footprint. 13 programs / 26 XEQ entry points across univariate / ANOVA / regression / hypothesis / nonparametric / distribution / RNG families. Authoritative source = the HP Stat 1 Pac Owner's Manual + QRC; Free42 NEVER copied (CI-gated).

## Milestone Summary

**Key Decisions:**

- `STAT_1.id = 2` (hardware XROM ID) — Pitfall 1 preserved, fires LAST
- `default_xrom_modules() → 0b0000_0011` + `migrate_after_load()` for v3.0 save-file forward-compat
- `rand_seed: HpNum` with `#[serde(default)]` WITHOUT `#[serde(skip)]` — only v3.1 exception
- `statrs` crate rejected — AS 239/63/241 hand-coded ~140 LOC in `stat1/distributions.rs`
- OM register layout transcription as named consts — P21 silent-wrong-answer trap mitigated before any Op written
